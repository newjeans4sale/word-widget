# word-widget — 영단어 바탕화면 위젯

작업 중인 화면 한구석에 영단어를 하나씩 띄워 두고 몇 초마다 바꿔 주는 위젯입니다.
따로 시간 내서 외우는 대신, 컴퓨터를 쓰는 내내 수동적으로 노출되는 것이 목적입니다.

보여주는 방식은 **두 가지**이고 트레이에서 오갑니다.

- **텍스트 모드** (기본) — 화면 구석에 글자만. 조용합니다.
- **마스코트 모드** — 작은 도트 캐릭터가 화면 바닥을 걸어다니며 머리 위
  말풍선으로 단어를 들고 다닙니다. 잡아서 옮길 수 있습니다.

- 클릭이 **통과**합니다. 위젯 위를 클릭하면 뒤쪽 창이 눌립니다.
- 단어 위에 **마우스를 올리면 한글 뜻**이 붙어 나옵니다. 클릭을 가로채지 않으므로
  통과 성질은 그대로 유지됩니다.
- 포커스를 **뺏지 않습니다**. 편집기에서 타이핑하는 중에도 커서가 끊기지 않습니다.
- 작업표시줄과 Alt+Tab에 뜨지 않습니다.
- 전체화면 앱(유튜브, 발표, 게임) 위에서는 알아서 숨습니다.
- 부팅 시 자동 실행되며, 평소에 끌 필요가 없습니다.

## 실행

```
.venv\Scripts\pythonw.exe main.py
```

`pythonw.exe`라 콘솔 창이 뜨지 않습니다. 종료는 트레이 아이콘 우클릭 > 종료.

처음부터 새로 설치하려면:

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install PySide6==6.8.3 pytest
```

> **PySide6는 6.8.3으로 고정합니다.** 이 PC(Windows 10 build 19045)에서 6.11.2는
> `ImportError: DLL load failed while importing QtCore` 로 뜨지 않습니다.
> Qt 6.8은 LTS이고 필요한 API가 전부 들어 있습니다.

## 단어 목록 — `words.txt`

한 줄에 한 항목. `단어, 뜻` 형식으로 적으면 마우스를 올렸을 때 뜻이 보입니다.
뜻 없이 단어만 적어도 됩니다. `#`로 시작하는 줄은 주석입니다.

```
# 내 단어장
ephemeral, 덧없는, 단명하는
ubiquitous, 어디에나 있는
laconic
```

- 구분자는 쉼표, 탭, `=` 를 모두 받습니다. **첫 구분자에서만** 쪼개므로
  `run, 달리다, 운영하다` 처럼 뜻 안에 쉼표가 있어도 그대로 유지됩니다.
- 뜻이 없는 단어는 마우스를 올려도 아무 일도 일어나지 않습니다.

- 인코딩은 신경 쓰지 않아도 됩니다. UTF-8과 CP949(메모장 ANSI 저장)를 모두 읽습니다.
- 앞뒤 공백, 빈 줄, 중복은 알아서 정리합니다.
- 수정한 뒤 트레이 > **다시 불러오기**를 누르면 즉시 반영됩니다. 재시작할 필요 없습니다.
- 파일이 비어 있거나 없으면 앱이 죽지 않고 안내 문구를 띄웁니다.

단어는 **셔플백** 방식으로 돕니다. 전체를 섞어 한 바퀴 다 쓰고 다시 섞기 때문에
모든 단어가 고르게 나오고, 같은 단어가 연달아 두 번 나오지 않습니다.

지나간 단어는 **최근 200개까지 기억**합니다. '이전 단어'로 되돌아간 뒤 '다음 단어'를
누르면 새로 뽑지 않고 왔던 길을 따라 돌아옵니다. 단어 목록을 다시 불러오면 기록은
지워집니다 — 삭제된 단어로 되돌아갈 수는 없어야 하니까요.

## 마스코트 모드

트레이 > **마스코트 모드**를 켜면 글자 대신 캐릭터가 나옵니다.

- 화면 바닥(작업표시줄 위)을 좌우로 **걸어다니고**, 가끔 멈춰 서거나 앉습니다.
  가만히 있게 하려면 트레이 > **산책**을 끄세요.
- **잡아서 끌 수 있습니다.** 놓으면 떨어져 바닥에 착지합니다.
  몸통을 클릭하면 다음 단어로 넘어갑니다.
- 캐릭터 **몸통 밖은 클릭이 통과합니다.** 텍스트 모드처럼 이동 모드를 켤 필요가
  없습니다 — 투명한 여백은 Windows 가 알아서 뒤쪽 창으로 넘깁니다.
- 마우스를 캐릭터 위에 올리면 말풍선에 **한글 뜻**이 붙고, **몸통 양옆에 ‹ ›**
  단추가 뜹니다. 눌러서 **지나간 단어로 되돌아가거나 다시 앞으로** 갈 수 있습니다.
  더 되돌아갈 데가 없으면 ‹ 가 흐려집니다.
  말풍선이 아니라 몸통에 얹는 이유는, 말풍선은 단어 길이에 따라 폭이 변해서
  누르는 도중에 단추가 커서 밑에서 빠져나가기 때문입니다.
- 커서를 올려 둔 동안에는 캐릭터가 **걷지 않고 단어도 자동으로 넘어가지 않습니다.**
  걸어가 버리면 읽던 뜻이 닫히고, 5초마다 바뀌면 화살표로 넘겨 보는 중에 손에서
  놓치기 때문입니다.
- 포커스를 뺏지 않는 것, 전체화면에서 숨는 것은 텍스트 모드와 같습니다.

### 캐릭터 추가하기

`sprites/<이름>/` 폴더를 만들고 PNG 를 넣으면 트레이 > **캐릭터**에 나타납니다.

```
sprites/
  dog/
    meta.json                     (선택)
    idle_0.png  idle_1.png        (필수 - 없으면 캐릭터로 인식하지 않습니다)
    walk_0.png  walk_1.png ...
    sit_0.png   sleep_0.png
```

쓰는 동작은 열 가지입니다.

| 동작 | 언제 |
|---|---|
| `idle` | **필수.** 서 있기 |
| `walk` / `run` | 걷기 / 뛰기 (뛰기는 2.6배 빠릅니다) |
| `sit` / `lie` / `sleep` | 앉기 / 엎드리기 / 자기 |
| `beg` / `bark` | 가끔 한 번씩 하는 짓 |
| `fall` | 놓아서 떨어지는 중 |
| `drag` | 잡혀 있는 중 |

없는 동작은 `sleep→lie→sit→idle`, `run→walk→idle` 처럼 알아서 대신합니다.
**그림이 없는 동작은 상태기계가 아예 고르지 않습니다** — 폴백으로 서 있는 그림이
나오면 몇 초 동안 아무 일도 안 일어나는 것처럼 보이기 때문입니다.
프레임이 하나뿐이면 `sit.png` 로 번호를 빼도 됩니다.

`meta.json` 은 전부 선택값입니다.

```json
{ "fps": 6, "scale": 2, "facing": "left", "actions": { "walk": { "fps": 10 } } }
```

| 키 | 뜻 |
|---|---|
| `fps` | 기본 재생 속도 |
| `scale` | 그림 배율. 도트는 정수배로 확대(뭉개지지 않음), 큰 그림은 1 미만으로 축소 |
| `facing` | **원본이 보는 방향.** 반대쪽은 좌우 반전으로 만들므로 그림은 한 벌만 있으면 됩니다 |
| `actions.<동작>.fps` | 그 동작만 다른 속도로 |

### 스프라이트시트에서 자르기

받은 그림이 격자 한 장이면 잘라 주는 도구가 있습니다.

```
.venv\Scripts\python.exe tools\import_sheet.py 시트.png --cell 60x38 --out sprites/dog ^
    --row 5=idle --row 1=walk --row 4=sit --trim --facing left --scale 2
```

`--trim` 은 **한 동작 안에서만** 공통 여백을 잘라냅니다. 프레임마다 따로 자르면
걸을 때 발이 위아래로 떱니다. 그림이 여러 파일에 나뉘어 있으면 두 번째부터
`--append` 를 붙여 같은 폴더에 이어 넣습니다.

### Shimeji 팩 가져오기

인터넷에 도는 Shimeji 캐릭터 팩(`shime1.png` ~ `shime46.png`)을 그대로 넣을 수 있습니다.

```
.venv\Scripts\python.exe tools\import_shimeji.py 받은폴더_또는_zip --out sprites/miku
```

번호와 동작의 대응은 shimeji-ee 의 기본 `conf/actions.xml` 을 따릅니다. 팩에 없는
프레임이 있으면 그 동작만 건너뜁니다. Shimeji 의 `Pinched`(머리를 집혀 대롱거리는
모습)가 우리 `drag` 에 그대로 들어맞아서, 잡아 끌면 실제로 대롱거립니다.

그림이 왼쪽을 보고 있지 않으면 `--facing right`, 너무 크거나 작으면 `--scale 0.8`
같은 식으로 조절합니다.

> 대부분의 Shimeji 팩은 기존 애니/게임 캐릭터를 그린 것입니다. 개인 사용 범위를
> 넘기지 않는 편이 안전합니다.

## 설정 — `config.json`

첫 실행 때 자동으로 만들어집니다. 수정 후 트레이 > 다시 불러오기.

| 키 | 기본값 | 설명 |
|---|---|---|
| `words_file` | `words.txt` | 단어 목록 경로 (상대경로는 이 폴더 기준) |
| `interval_sec` | `5.0` | 단어가 바뀌는 간격 (1 ~ 3600) |
| `font_size_pt` | `14` | 글자 크기 (6 ~ **18**) |
| `font_family` | `Segoe UI` | 없는 글꼴이면 자동 대체하고 로그에 남깁니다 |
| `color` | `#FFFFFF` | 글자색 (`#rgb`, `#rrggbb`, `#aarrggbb`) |
| `outline_color` | `#000000` | 외곽선 색. 밝은 배경화면에서도 읽히게 해 줍니다 |
| `opacity` | `0.85` | 불투명도 (0.1 ~ 1.0) |
| `anchor` | `bottom-right` | 기준 모서리. 드래그하면 자동으로 정해집니다 |
| `anchor_x` / `anchor_y` | 자동 | 기준 모서리의 좌표. 드래그 시 자동 저장 |
| `hide_on_fullscreen` | `true` | 전체화면 앱 위에서 숨김 |
| `paused` | `false` | 시작할 때 멈춘 상태로 띄울지 |
| `mode` | `text` | `text` 또는 `mascot` |
| `character` | `tan` | `sprites/` 안의 폴더 이름. 없으면 첫 번째 것으로 대체 |
| `mascot_scale` | `1.0` | 캐릭터 크기 배율 (0.25 ~ 4.0). `meta.json` 의 `scale` 에 곱해집니다 |
| `mascot_wander` | `true` | 스스로 걸어다닐지 |
| `mascot_x` / `mascot_y` | 자동 | 캐릭터의 마지막 발밑 좌표 |
| `bubble` | `true` | 말풍선을 띄울지 |

간격·글자 크기·글꼴·색·투명도·전체화면 숨김은 두 모드가 함께 씁니다.

**글자 크기 상한 18pt는 코드에 박혀 있습니다.** 이 PC의 바탕화면 아이콘 라벨 글꼴이
9pt이고, 그 2배를 상한으로 두기로 했기 때문입니다. 값은 실행할 때마다 OS에서 직접 읽으므로
디스플레이 배율을 바꿔도 비율이 유지됩니다. `config.json`에 100을 적어도 18로 잘립니다.

## 트레이 메뉴

| 항목 | 설명 |
|---|---|
| 일시정지 | 단어 회전을 멈춥니다 |
| 이전 단어 | 지나간 단어로 되돌아갑니다. 처음이면 흐려집니다 |
| 다음 단어 | 즉시 다음 단어로 (일시정지 중에도 동작). 트레이 아이콘 더블클릭도 같습니다 |
| **이동 · 크기 조정** | 켜면 점선 테두리와 손잡이가 생깁니다. 끄면 다시 클릭 통과 (텍스트 모드에만) |
| **마스코트 모드** | 글자 ↔ 캐릭터 전환 |
| 산책 | 캐릭터가 스스로 걸어다닐지 (마스코트 모드에만) |
| 캐릭터 | `sprites/` 에 있는 캐릭터 중 고르기 (마스코트 모드에만) |
| 기본값으로 되돌리기 (모양·위치) | 글자 크기·간격·색·위치를 기본값으로. **단어 목록 경로는 건드리지 않습니다** |
| 다시 불러오기 | `words.txt`와 `config.json`을 모두 다시 읽습니다 |
| 단어 목록 열기 / 설정 열기 | 기본 편집기로 엽니다 |
| Windows 시작 시 실행 | 자동 실행 등록/해제 |
| 종료 | |

> **아이콘이 안 보이면** 작업표시줄 우측의 `^` (숨겨진 아이콘 표시)를 눌러 보세요.
> Windows는 새로 등록된 트레이 아이콘을 기본적으로 숨김 영역에 넣습니다.
> 거기서 시계 옆으로 끌어다 놓으면 항상 보이게 고정됩니다. 이 위젯은 트레이가
> 유일한 조작 수단이므로 고정해 두는 편이 편합니다.

평소에는 클릭이 통과하므로 드래그가 안 됩니다. 옮기거나 크기를 바꿀 때만
**이동 · 크기 조정**을 켜세요. 켜면 단어 주변에 **반투명 회색 사각형과 점선 테두리**,
그리고 한쪽 모서리에 **점 세 개짜리 손잡이**가 생깁니다.

| 어디를 잡느냐 | 무슨 일이 일어나나 |
|---|---|
| 사각형 안 아무 데나 | 위젯을 **옮깁니다**. 글자 위가 아니어도 됩니다 |
| 모서리의 **손잡이** | 글자 **크기**를 바꿉니다 |

손잡이는 고정된 모서리(앵커)의 **대각선 반대편**에 붙습니다. 위젯이 우측 하단에 있으면
손잡이는 좌측 상단입니다. PPT 의 모서리 핸들처럼 **끄는 방향은 상관없습니다** — 앵커에서
멀어지면 커지고 가까워지면 작아집니다. 가로로 끌든 세로로 끌든 대각선으로 끌든
같은 정도로 반응합니다. 약 12px 당 1pt 이고, 6pt ~ 18pt 를 벗어나면 더 이상 변하지 않습니다.

드래그 중에는 창 크기가 손 밑에서 바뀌지 않도록 단어 회전이 잠시 멈춥니다.

전환할 때 창이 한 번 깜빡입니다. 클릭 통과를 끄려면 Qt 창 플래그를 실제로 바꿔야 하고
(네이티브 스타일 비트만 바꾸면 OS 는 클릭을 넘겨주는데 Qt 가 위젯까지 전달하지 않는다),
플래그를 바꾸면 Qt 가 네이티브 창을 다시 만들기 때문입니다.

## 자동 실행

트레이 > **Windows 시작 시 실행**을 켜면
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 등록됩니다. 관리자 권한이 필요 없습니다.

## 문제가 생기면 — `word-widget.log`

`pythonw.exe`로 돌기 때문에 콘솔이 없습니다. 예외가 나면 이 폴더의 `word-widget.log`에
스택 트레이스가 남습니다. 앱이 안 뜨면 이 파일부터 보세요. 시작 시 인터프리터 경로와
Qt 플러그인 경로도 함께 기록합니다.

## 테스트

```
.venv\Scripts\python.exe -m pytest -q             # 168개, Qt 없이 도는 로직
.venv\Scripts\python.exe tools\verify_gui.py      # 창 동작 (스타일, 드래그, 전체화면)
.venv\Scripts\python.exe tools\verify_app.py      # 앱 동작 (트레이 메뉴, 뜻 보기, 크기)
.venv\Scripts\python.exe tools\verify_mascot.py   # 마스코트 (클릭 판정, 드래그, 모드 전환)
```

`verify_gui.py` 와 `verify_app.py` 는 **진짜 마우스 입력**을 만들어 검증하므로 실행 중
커서가 잠깐 움직입니다(끝나면 제자리로 되돌립니다). 실행 중에는 마우스를 쓰지 마세요 —
커서를 뺏기면 호버 검증은 실패가 아니라 '건너뜀'으로 보고됩니다.

Qt 이벤트를 위젯에 직접 주입하는 방식으로는 부족합니다. OS 의 클릭 판정과 Qt 의 이벤트
전달을 둘 다 건너뛰기 때문에, 실제로 '점선은 보이는데 드래그가 안 되는' 버그를 통과시킨
적이 있습니다.

pytest는 반드시 **프로젝트 루트에서** 실행하세요. `sys.path`에 루트가 들어가야 import가 됩니다.
`verify_gui.py`에 파일 경로를 넘기면 위젯을 캡처한 PNG도 저장합니다.

## macOS

코드는 플랫폼을 가려 동작하지만 이 기기에서 검증하지 못했습니다. 알려진 제약:

- `WA_MacAlwaysShowToolWindow`를 켜 두었습니다. 이게 없으면 앱이 최전면이 아닐 때
  창이 사라져 사실상 거의 안 보입니다.
- pyobjc 없이는 **Dock 아이콘을 숨길 수 없습니다.** `.app` 번들로 묶고
  `Info.plist`에 `LSUIElement = 1`을 넣는 것이 유일한 우회입니다.
- **모든 Space에 표시할 수 없습니다.** 위젯이 만들어진 Space에만 있습니다. 우회 방법 없음.
- **다른 앱의 전체화면 Space 위에는 그릴 수 없습니다.** 우회 방법 없음.
- 클릭 통과 토글에 네이티브 경로가 없어 전환 시 한 프레임 깜빡입니다.
- 글자 크기 상한은 24pt입니다 (Finder 아이콘 라벨 12pt의 2배).

## 구조

```
main.py          부트스트랩: 로깅, 단일 인스턴스, QApplication
app.py           컨트롤러: 타이머, 상태, 각 모듈 연결
config.py        설정 로드/저장 + 검증          (Qt 없음, 테스트됨)
wordsource.py    단어 로딩 + 셔플백             (Qt 없음, 테스트됨)
osfont.py        OS 아이콘 글꼴 크기 읽기       (Qt 없음)
platform_win.py  클릭 통과, 자동 실행 레지스트리 (Windows 전용)
fullscreen.py    전체화면 감지                  (Windows 전용)
overlay.py        텍스트 오버레이 창
mascot.py         마스코트 상태기계 (걷기/앉기/낙하)  (Qt 없음, 테스트됨)
sprites.py        캐릭터 폴더 읽기 + 픽스맵 캐시      (스캔 부분은 Qt 없음, 테스트됨)
mascot_overlay.py 마스코트 오버레이 창
tray.py           트레이 아이콘과 메뉴
```

`mascot.py` 는 Qt 도 시간도 난수도 직접 만들지 않습니다. `update(dt, bounds)` 만
받으므로 테스트에서 시드와 dt 를 고정해 몇 분치를 즉시 돌려볼 수 있습니다.
그리는 일은 전부 `mascot_overlay.py` 에 있습니다.
